# myFirstAlgorithm
The purpose of this algorithm is for students to easily and effectively order items from the school canteen online. The way the algorithm works is when students come to order food the algorithm will ask them for their name, as they need to save the input to the reciept. The workers making the order know it is yours, and they will then ask you to input more of the items from the canteen (as many as you want.) You can select more than one and two items as there are multiple options. Once the user has finished selecting all his items the algorithm will break into another line of code where it will determine whether a discount should be applied based on the items bought from here and if theres a discount 10 percent is taken off otherwise no discount and either way (discount or no discount) a reciept is dispayed at the end with your name and the final cost you paid
